nineku.fm
=================

### 介绍：

----------------------------

`http://www.9ku.com/fm 的终端版本`


### 安装:

---------------------------------------

``` sh
sudo apt install mpv -y
npm install -g nineku.fm
```

### 运行:

---------------------------------

`nineku.fm`
